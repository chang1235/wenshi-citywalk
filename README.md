# 文市相逢｜台中文學館與第五市場

> 以腳步為序，讀一座城。

## 一、專題介紹

本專題以「文市相逢」為主題，串聯臺中文學館與第五市場兩處具有不同城市特色的場域，透過城市漫遊（Citywalk）的方式，帶領旅人重新認識臺中舊城。

臺中文學館呈現日式歷史建築與文學文化的靜謐氛圍；第五市場則展現傳統市場的飲食文化、在地特色與日常人情味。

希望透過網站與影像紀錄，讓 18 至 28 歲、喜愛城市漫遊及影像紀錄的年輕族群，從不同角度感受臺中舊城的文化與生活。

## 二、網站設計理念

**核心概念：一處靜謐，一處熱鬧，都是舊城的風景。**

以臺中文學館的歷史人文與第五市場的常民生活作為雙核心，透過網站導覽、場域介紹、城市漫遊路線及影像紀錄，呈現兩處場域的特色與連結。

視覺設計以日式文學編輯風格為方向，運用米白、暖棕及橄欖綠等色彩，搭配留白、文字層次與實地拍攝照片，營造具有文化感的閱讀體驗。

## 三、目標客群

- 年齡：18～28 歲。
- 喜愛城市漫遊與探索在地文化。
- 習慣透過照片及影像記錄旅途與生活。
- 對歷史建築、傳統市場及地方文化具有興趣的年輕旅人。

## 四、網站功能與內容

1. **企劃概念：** 介紹專題理念與城市漫遊的核心概念。
2. **臺中文學館：** 呈現歷史建築、文學文化與場域特色。
3. **第五市場：** 介紹傳統市場、在地飲食與常民生活。
4. **城市漫遊：** 串聯兩處場域，呈現步行探索的概念。
5. **影像紀錄：** 展示專題影像及場域介紹影片。
6. **參訪資訊：** 提供場域位置、地圖及參訪資訊。
